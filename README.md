# Academic Library Management System

## Problem Statement

The existing academic library system involves manual book issue
and return processes, inventory mismatch, delayed fine reminders,
and separate digital resources.

## Objectives

- Automate book issue and return
- Provide quick book search
- Maintain accurate inventory
- Provide online fine payment
- Send automated due-date reminders
- Provide analytics for librarians

## Features

- Student login
- Book search
- RFID-based book issue
- Book return
- Fine management
- Digital resources
- Librarian dashboard

## Technologies Used

- HTML
- CSS
- JavaScript
- RFID/IoT
